# 여운 — 손짓으로 만나는 3D 전시관

4팀 44xla · 대덕전자 미션 (고등학생 해커톤)

창고에 보관된 장애 예술인 작품을 **3D 온라인 전시관** 벽에 걸고, 버튼·방향키·**손 기울이기**로 넘겨 보며 **관심 저장과 한마디**를 남기면, 담당자가 관리자 페이지에서 관람 반응을 확인합니다.

| 화면 | 주소 |
|---|---|
| 3D 전시관 | `http://127.0.0.1:8000/` |
| 관리자 (PIN: `config.json`의 `admin_pin`) | `http://127.0.0.1:8000/admin` |
| 작동 가이드 | `http://127.0.0.1:8000/guide` |

## 구성
- **Python 로컬 서버** `server.py` — 웹 화면 제공, API, 제스처 이벤트(SSE), 카메라 화면(MJPEG, 같은 PC에서만)
- **손 인식** `gesture.py` — OpenCV로 웹캠을 읽고 MediaPipe Hand Landmarker로 손의 21개 점을 찾아, 손목→가운데 손가락 뿌리의 기울기(각도)로 NEXT/PREV 판정
  - 오른쪽으로 30° 이상 0.2초 유지 → 다음 작품 / 왼쪽 → 이전 작품
  - 넘긴 뒤 손을 다시 세워야 다음 넘김, 1초 대기, 이동 애니메이션 중에는 명령 무시
  - 명령마다 고유 번호(id)를 붙여 중복 실행 방지
- **DB** `db.py` — SQLite `data/yeoun.db` (rooms, artists, artworks, locations, likes, comments, events)
- **엑셀 가져오기** `import_excel.py` — 관리용 엑셀의 작품 목록·셀 내 이미지·위치 시트를 읽어 DB와 이미지 생성 (표준 라이브러리 + Pillow)
- **웹** `web/` — Three.js r147 전시관(`index.html`, `js/gallery.js`, `js/floorplan.js`), 관리자 페이지(`admin.html`)

## 실행 (Windows)
1. Python 3.11 설치 (설치 화면에서 "Add python.exe to PATH" 체크)
2. 관리용 엑셀(`대덕전자 장애 예술인_작품 리스트(관리용)_*.xlsx`)을 이 폴더의 **상위 폴더**에 두기 (또는 `config.json`의 `excel_path` 수정)
3. `시작하기.bat` 더블클릭 → 라이브러리 설치, three.js·손 인식 모델 다운로드, 엑셀로 DB 생성, 서버 실행

직접 실행: `pip install -r requirements.txt` → `python setup_assets.py` → `python import_excel.py` → `python server.py`

## 이 저장소에 없는 것 (의도적으로 제외)
공개 저장소이므로 **작가 실명, 사내 설치 위치, 관리용 엑셀에서 꺼낸 작품 이미지가 들어 있는 `data/`와 엑셀 파일은 올리지 않습니다** (`.gitignore`). 엑셀을 받은 담당자 PC에서 `python import_excel.py`로 만들어 씁니다.

## 지키는 원칙
- 손 인식 AI(MediaPipe)와 작품 소개문은 별개입니다. 소개문 초안은 엑셀 '작품 설명'(제공 자료)을 옮긴 것이며 AI가 쓴 글이 아니고, 담당자 승인 후에만 공개됩니다.
- 작가의 의도·이력을 지어내지 않고, 실제 자료가 없는 항목에는 '예시'를 표시합니다.
- 가상 전시 위치(전시실 n번 자리)와 실제 보관/설치 위치(담당자 입력)를 구분해 보여 줍니다.
- 공개 화면의 작가명은 익명 표시명이 기본이며, 실명은 동의 확인 후에만 공개합니다.
- 관심·한마디 수는 관람 참여 기록이며 사회공헌 효과 전체가 아닙니다.
- 웹캠 영상은 저장하지 않고, 카메라 화면은 같은 PC(127.0.0.1) 브라우저에만 보여 줍니다.
- 로컬 시연용입니다. 인터넷 배포 시 손 인식은 방문자 브라우저(MediaPipe for Web)로 옮겨야 합니다 — 서버의 웹캠은 방문자의 웹캠이 아닙니다.

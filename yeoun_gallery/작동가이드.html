1무엇을 만들었나

창고에 보관된 장애 예술인 작품을 3D 온라인 전시관의 벽에 걸고, 버튼·방향키·손 기울이기로 넘겨 보며 관심 저장과 한마디를 남기면 담당자가 관리자 페이지에서 반응을 확인하는 서비스예요.

  • 전시관 건물: 3d 폴더의 평면도 건물(5개 전시실)을 그대로 쓰고, 벽마다 작품 걸 자리와 감상 지점을 자동으로 계산해요.
  • 작품: 엑셀 2.작품 리스트_RAWDATA 시트의 157점(이미지 있는 156점 전시)을 테마별로 나눴어요.
    1전시실 가족 · 2전시실 이야기 · 3전시실 자연 Ⅰ(2025–2026 인수) · 4전시실 자연 Ⅱ(2023–2024 인수) · 5전시실 감정
  • 이미지: 엑셀 '사진' 칸의 미리보기는 칸 크기에 맞춰 눌려 있어서, 숨김 시트(2-1.작품 리스트_가공용 등)에서 같은 그림을 자동으로 찾아 원본 비율 그림을 썼어요. 못 찾은 41점은 관리자 페이지에 '비율 확인 필요'로 표시돼요.
  • 작가 이름: 공개 화면은 익명 표시명(예: 강○혜)이 기본이에요. 실명은 관리자 화면에서만 보여요.
  • 데이터베이스: 작품·전시실·작가 표시명·소개문·위치·관심·한마디는 모두 data/yeoun.db(SQLite)에 저장돼요. 'DB Browser for SQLite' 프로그램으로 열어 볼 수 있어요.

2처음 실행하기 (Windows)

  1. Python 설치 — python.org에서 Python 3.11(3.10~3.12)을 설치해요. 설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크해요.
    MediaPipe는 아주 최신 Python에서는 설치가 안 될 수 있어요. 3.11이 가장 무난해요.
  2. yeoun_gallery 폴더에서 시작하기.bat을 더블클릭해요.
    • 처음 한 번만 제스처용 라이브러리(opencv-python, mediapipe, pillow)를 설치하고, 3D 라이브러리와 손 인식 모델을 내려받아요. 인터넷이 필요하고 몇 분 걸려요.
    • 그다음 서버가 켜지고 브라우저가 http://127.0.0.1:8000으로 자동으로 열려요.
  3. 끝낼 때는 검은 서버 창에서 Ctrl+C를 누르거나 창을 닫아요. 카메라도 함께 해제돼요.
주소화면
http://127.0.0.1:8000/3D 전시관 (방문자 화면)
http://127.0.0.1:8000/admin관리자 페이지 · PIN 기본값 4444 (config.json의 admin_pin)
http://127.0.0.1:8000/guide이 가이드

직접 실행하려면: python -m pip install -r requirements.txt → python setup_assets.py → python server.py

index.html을 더블클릭해서 열면 안 돼요. 데이터와 제스처가 서버를 거치기 때문에, 반드시 서버를 켠 뒤 위 주소로 열어야 해요.

3시연 전 준비 (10분)

  1. 소개문 승인 — 관리자 → 소개문 검토 → 전시실을 '1전시실'로 고르고 작품을 하나씩 확인해 승인하고 공개를 눌러요. 처음에는 모든 소개문이 '검토 대기'라서 전시관에는 "소개문 검토 중"으로 보여요.
  2. 위치 확인 — 작품 관리에서 시연에 쓸 작품의 '현재 위치'가 맞는지 확인해요. 엑셀 설치위치가 빈칸이면 '확인 필요'로 표시돼요.
  3. 제스처 리허설 — 시연 장소 조명에서 제스처 모드를 켜고 감도를 맞춰요(6번 참고). 웹캠은 사람 상반신이 다 들어오게 두고, 뒤쪽이 너무 밝은 창문은 피해요.
  4. 반응 초기화 — 리허설에서 남긴 관심·한마디는 관리자 → 관람 반응 → 시연 전 반응 기록 초기화로 지워요.
  5. 오프라인 대비 — setup_assets.py를 한 번 실행했다면 인터넷 없이도 3D 화면과 제스처가 동작해요. (글꼴만 기본 글꼴로 바뀌어요)
특정 작품에서 바로 시작하려면 주소 뒤에 #room=1&i=3(1전시실 3번째 작품)을 붙여요.

4시연 순서 — 버튼 이동 → 손동작 이동 → 관심·반응 반영

  1. 전시관 첫 화면에서 건물 전체를 보여 주며 "창고에 있던 작품 156점이 5개 전시실에 걸려 있어요"라고 소개해요.
  2. 1전시실 클릭(또는 '입장하기') → 시점이 실내로 내려가 첫 작품이 정면에 보여요.
  3. '다음 작품' 버튼 2번, → 키 1번을 눌러 번호가 1 / 18 → 4 / 18으로 바뀌는 걸 보여 줘요. 오른쪽 카드에서 작품명 · 작가 표시명 · 승인된 소개문 · 실제 위치와 가상 전시 위치가 따로 나오는 것도 짚어 줘요.
  4. '제스처 모드 시작' → 상태가 준비 중 → 손 찾는 중 → 손 인식됨으로 바뀌어요.
  5. 패널의 카메라 화면에 손 뼈대와 기울기 선이 그려지는 걸 보여 줘요. 손바닥을 화면 쪽으로 펴고 손을 똑바로 세우면 준비 완료(점이 보라색).
  6. 손을 오른쪽으로 30° 정도 기울여 잠깐(0.2초) 유지하면 '다음 작품 이동', 왼쪽이면 '이전 작품 이동'이에요.
  7. 손을 다시 세우는 동작이나 살짝 흔드는 동작은 넘어가지 않는 것을 보여 줘요 (다시 세워야 다음 넘김 · 1초 대기).
  8. 마음에 드는 작품에서 ♡ 관심 저장을 누르고, 한마디("색이 따뜻해요")를 남겨요.
  9. 관리자 페이지 → 현황판 / 관람 반응에서 관심 +1과 한마디가 반영된 걸 보여 줘요. 이때 "반응 수는 관람 참여 기록이에요"라고 덧붙여요.
  10. '제스처 모드 종료' → 상태가 '웹캠 꺼짐'으로 바뀌고 카메라가 해제돼요.

5전시관 조작법

하고 싶은 것방법
전시실 들어가기건물의 전시실 바닥·라벨 클릭, 오른쪽 전시실 목록 클릭, 숫자키 1~5
작품 넘기기하단 '이전 작품 / 다음 작품', ← →, 손 기울이기, 같은 방 다른 작품 클릭
전시실 끝에서다음 전시실 첫 작품으로 자동 이동해요 (5전시실 다음은 1전시실)
전체 보기로 나가기상단 '전시관 전체 보기' 또는 Esc
작품 찾기상단 '작품 찾기' 또는 / → 작품명 · 작가 표시명 · 주제(꽃, 가족, 호랑이…) → 결과를 누르면 그 작품 앞으로 이동
작품 크게 보기작품 카드의 '크게 보기' → 원본 비율·색 그대로 2D로 보여요
건물 둘러보기전체 보기에서 드래그 회전 · 휠 확대 · 우클릭 드래그 이동, '벽 낮추기' · '평면' · '회전'

이동 애니메이션 중에는 버튼·키·손짓 명령을 모두 무시해요 (중복 이동 방지). 경로가 벽에 막히는 L자 전시실에서는 부드러운 화면 전환(페이드)으로 이동해요.

6제스처 모드(손 기울이기)와 감도

작동 방식

웹캠 → gesture.py (OpenCV로 읽기 → MediaPipe Hand Landmarker로 손의 21개 점
       → 손목(0번)→가운데 손가락 뿌리(9번) 방향이 세로선에서 몇 도 기울었는지 계산)
     → 오른쪽으로 30° 이상, 0.2초 유지 = NEXT / 왼쪽 = PREV
     → server.py가 {"id": 17, "cmd": "NEXT"} 이벤트 발행
     → 브라우저(EventSource)가 받아서, 이미 처리한 번호면 무시 / 이동 중이면 무시 / 아니면 다음 작품으로
  • 카메라는 '제스처 모드 시작'을 눌렀을 때만 켜지고, 종료하면 해제돼요.
  • 카메라 화면: 제스처 패널에 웹캠 화면(거울 모드)과 손 뼈대 · 기울기 선 · 각도가 보여요. 서버가 이 PC(127.0.0.1)의 브라우저에만 보내고 다른 PC에서의 접속은 거부해요. 저장하지 않아요. 설정에서 '카메라 화면 보기'를 끌 수 있어요.
  • 패널의 막대: 가운데 회색 = 손을 세운 범위, 양쪽 보라색 = 넘김 각도. 점이 회색이면 "손을 세워 주세요", 보라색이면 준비 완료예요.
  • 각도는 화면 기준(거울)이에요. 사용자가 보기에 오른쪽으로 기울이기 = 다음.

판정 규칙과 조절 값 (config.json → gesture)

값기본뜻 · 언제 바꾸나
tilt_angle30이 각도(도) 이상 기울여야 넘김. 잘 안 넘어가면 ↓, 너무 잘 넘어가면 ↑
hold_time0.2기울인 채 유지해야 하는 시간(초). 흔들림에 넘어가면 ↑
neutral_angle12이 각도 안이면 '손을 세운 상태'. 넘긴 뒤에는 손을 다시 세워야 다음 넘김 (되돌리는 동작은 넘김 아님)
cooldown1.0한 번 넘긴 뒤 추가 넘김을 막는 시간(초)
arm_time0.3손이 처음 보인 뒤 판정을 시작하기까지 시간. 처음부터 기울어진 손은 한 번 세워야 해요
modetiltswipe로 바꾸면 예전 방식(손을 좌우로 휘두르기)
videotrue전시관 화면에 카메라 화면 보이기
camera_index0외장 웹캠이면 1로

전시관 화면의 제스처 패널에서 설정 아이콘을 누르면 넘김 각도 · 유지 시간 · 대기 시간을 슬라이더로 바로 바꿀 수 있고 config.json에 저장돼요. NEXT / PREV 테스트 버튼은 카메라 없이 서버 → 웹 연결만 확인해요.

카메라만 따로 확인하려면 python gesture.py (확인 창 + 콘솔에 NEXT/PREV 출력)

작품 관리상태(보관 중 · 설치됨 · 대여·외부 전시 · 확인 필요)와 현재 위치 수정(엑셀 '위치' 시트 장소가 자동 완성), 가상 전시실 배정, 전시관 공개 여부, 이미지 교체(비율 확인 필요 작품용)
소개문 검토왼쪽 목록에서 작품 선택 → 엑셀 '작품 설명' 원문과 초안 비교 → 수정 → 승인하고 공개 / 보류 / 공개 취소. 원문에 작가 실명이 있으면 초안에서 표시명으로 바꿔 두고 알려 줘요.

관람 반응최근 한마디(숨기기·삭제), 작품별 관심 수, 시연 전 반응 초기화
설정 · 엑셀엑셀 다시 불러오기, 전시실 이름·테마 수정, 작가 표시명과 실명 공개(동의 확인 시에만)

8엑셀 다시 불러오기

담당자가 엑셀을 고쳤다면 관리자 → 설정 · 엑셀 → 엑셀 다시 불러오기 (또는 엑셀_다시_불러오기.bat).

  • 엑셀 위치는 config.json의 excel_path (기본: 상위 폴더의 대덕전자 장애 예술인_작품 리스트(관리용)_20261008.xlsx). 파일 이름이 바뀌면 이 값을 고쳐요.
  • 관리자 페이지에서 고친 위치 · 상태 · 소개문 승인 · 전시실 배정 · 작가 표시명은 그대로 유지돼요. 엑셀 '작품 설명' 원문이 바뀐 작품만 소개문이 다시 '검토 대기'가 돼요.
  • 엑셀 원본은 읽기만 하고 수정하지 않아요. '작가사진' 시트는 쓰지 않아요.
  • 이미지 매칭(같은 그림 찾기)과 크기 줄이기는 Pillow가 있어야 해요 (requirements.txt에 포함).

10문제 해결

증상해결
"서버에 연결할 수 없어요"index.html을 직접 연 경우예요. 시작하기.bat로 서버를 켜고 http://127.0.0.1:8000으로 열어요.
"3D 라이브러리를 불러오지 못했어요"인터넷 연결 확인 후 python setup_assets.py를 실행해 web/vendor에 파일을 받아요.
제스처 상태가 '오류 · OpenCV/MediaPipe가 설치되어 있지 않아요'python -m pip install -r requirements.txt. 설치 실패 시 Python 3.11로 다시 설치해요.
'손 인식 모델이 없어요'python setup_assets.py. 안 되면 아래 주소의 파일을 받아 models/hand_landmarker.task로 저장해요.
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
'웹캠을 열 수 없어요'Zoom·카메라 앱 등 다른 프로그램을 끄고, Windows 설정 → 개인 정보 → 카메라 접근을 허용해요. 외장 웹캠이면 camera_index를 1로.
손을 기울여도 안 넘어감손바닥 전체가 화면에 보이게 펴고, 먼저 손을 똑바로 세워 점이 보라색이 되게 한 뒤 기울여요. 슬라이더에서 '넘김 각도'를 낮춰요.
카메라 화면이 안 보임제스처 모드가 켜져 있는지, 설정의 '카메라 화면 보기'가 켜져 있는지 확인. 다른 PC에서 접속한 경우에는 보이지 않아요(보안).
반대로 넘어감config.json의 mirror를 false로 (카메라가 이미 좌우 반전된 영상을 줄 때).
포트 8000이 사용 중서버가 자동으로 8001~8009를 찾아요. 서버 창에 나온 주소로 접속해요.
작품이 흐리거나 비율이 이상함엑셀에 작은 미리보기만 있는 작품이에요(관리자 '비율 확인 필요'). 원본 사진으로 '이미지 교체'해요.

11꼭 지킬 원칙 (발표 때도 이렇게 설명)

  • AI 두 가지를 구분해요. 이 프로젝트의 AI는 웹캠 손 인식(MediaPipe)뿐이에요. 소개문 초안은 엑셀 '작품 설명'을 옮겨 정리한 것이고 AI가 쓴 글이 아니에요. "MediaPipe로 소개문도 만들었다"고 말하지 않아요.
  • 지어내지 않아요. 작가의 의도 · 이력 · 작품 이야기는 제공 자료에 있는 것만 써요. 실제 자료가 없는 작품 · 작가 · 장소에는 '예시'를 표시해요.
  • 위치를 구분해요. '가상 전시 위치(예: 2전시실 7번 자리)'는 온라인 전시관 안의 자리이고, '실제 위치(예: HQ 식당 / 창고 보관)'는 담당자가 입력한 사내 보관·설치 장소예요.
  • 반응 수를 과장하지 않아요. 관심 · 한마디 수는 온라인 관람 참여 기록이에요. 사회공헌 효과 전체로 해석하지 않아요.
  • 작가 정보를 보호해요. 공개 화면은 익명 표시명이 기본이고, 실명 공개는 동의를 확인한 경우에만 켜요. 작가 사진은 쓰지 않아요.
  • 범위 밖: 결제 · 기부 처리 · 회원가입 · 사내 시스템 연동 · VR · 자유 걷기 · 멀티플레이.

인터넷 배포는 별도 단계

지금 구조는 Python과 브라우저가 같은 PC에 있는 로컬 시연용이에요. 서버는 127.0.0.1에만 열려요. 이 서버를 인터넷에 그대로 올리면 서버 PC의 웹캠이 켜질 뿐 방문자의 웹캠이 아니에요. 배포할 때는 손 인식을 방문자 브라우저 안(MediaPipe for Web)으로 옮기고, 관리자 로그인 · HTTPS · 반응 저장소를 따로 준비해야 해요.
